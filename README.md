# Python-App
Dental Treatment Tracker

The Dental Treatment Tracker is a beginner-friendly Python command-line application designed to manage basic dental treatment information.

The program allows users to add patients, view existing patient records, search for a patient by name, update treatment status, calculate the total value of pending treatment, and save patient data to a JSON file.

I built this project to practice core Python concepts while creating something connected to my background in the dental field.

Features

Add new patients

View all patient records

Search for patients by name

Update treatment status

Calculate the total value of pending treatment

Save patient data to a JSON file

Automatically load saved patient data when the program starts

Variables

Lists

if, elif, and else statements

while loops

for loops

User input

String methods

Type conversion

File handling

JSON

Exception handling

How to Run

Make sure Python is installed on your computer.

Clone or download the repository, open the project folder in a terminal, and run:

python main.py

Follow the numbered menu options to use the application.

Project Purpose

This project was created as one of my first independent Python portfolio projects after completing introductory Python coursework. My goal was to apply what I learned to a practical program rather than only completing individual exercises and labs.

Future versions may include additional validation, object-oriented programming, database storage, and a web-based interface.
